# GoGo · 围棋局面分析助手

按 [MVP-PRD.md](./MVP-PRD.md) 实现的本机网页应用。Vue 3 + TypeScript + Vite，FastAPI，IndexedDB。本项目独立实现，通过 HTTP 使用本机已有 KataGo 服务；中文解释固定接入 DeepSeek。

**本次仅完成源码、配置和锁文件编写。未安装项目运行依赖，未运行构建、测试、Lint、类型检查、浏览器自测或本地服务，未请求 KataGo / DeepSeek 分析。以下命令供你决定运行时使用。**

## 使用

1. 点击“导入棋谱”，选择项目内的 `test.sgf` 或自己的单盘棋谱。
2. 根节点规则或贴目缺失时，明确选择后才会保存。
3. 使用左右按钮、键盘方向键或手数滑块浏览。第 N 手表示前 N 手已经走完。
4. 点击“分析当前局面”，向 KataGo 发送初始摆子和前 N 手完整历史。
5. 引擎结果先写入本地，再自动生成中文解释；A 是首选，最多展示 A / B / C。
6. AI 失败时使用“重新生成解释”，不会再次请求 KataGo。重新分析失败保留旧结果。
7. 关闭页面后，在同一地址和 Chrome 配置下打开，自动恢复最近棋谱与浏览位置。

页面同时只处理一个分析或解释流程，过程中可以浏览其他步骤或棋谱。迟到结果写入发起时的棋谱和手数，不覆盖当前另一局面。不会在导入、浏览、恢复缓存时自动发起分析。

停一手计入手数，推荐停一手时不在棋盘上画假坐标。所有候选数值均为黑方视角，正领先为黑方领先，负领先为白方领先。引擎 `order` 决定推荐顺序；不会按胜率高低重新排名。

## SGF 范围

- UTF-8（含 BOM），最大 2 MB；9 / 13 / 19 路正方形棋盘。
- 使用 `@sabaki/sgf` 解析、`@sabaki/go-board` 处理前端棋盘，后端用 sgfmill 独立校验。
- 支持根节点 AB / AW / AE（含压缩点列表）、HA、PL、KM、RU，以及主线普通着手、提子和停一手。
- 支持 `RU[Chinese]` / `RU[chinese]` 和 `RU[Japanese]` / `RU[japanese]`，规则名忽略大小写及首尾空白；其他值要求手动确认，不猜测规则。
- 中国规则对应 KataGo `chinese`，日本规则对应 `japanese`。两种均禁止自杀、使用简单劫；`chinese-ogs` / `chinese-kgs` 不自动视为同一规则。引擎仍接收完整历史。
- `HA>=2` 时要求实际 AB 数量一致，不补造让子位置。PL 优先，缺失时让子棋轮白，否则轮黑；检查所有主线着手的行棋方。
- 多分支只浏览第一个分支；`test.sgf` 的教学分支、C 注释、LB 候选标记保留在原文，不参与新分析与 AI 输入。
- 多盘集合、中途摆子 / 规则 / 贴目 / 行棋方 / 尺寸变化、KO 强制非法落子、损坏语法、非法落子和不支持编码明确拒绝。
- 不提供终局裁判、试下、编辑或分支切换；最后记录的局面仍可主动分析。

## 本地保存和删除

数据库名 `gogo-review`，schema 版本 1；仅有 `games` 与 `analyses` 两个对象仓库。棋谱 ID 为固定键顺序 `{ sgfText, rules, komi }` 的 SHA-256，分析键为 `[gameId, moveIndex]`。不以文件名去重。

棋谱、最后浏览手数、分析和解释均保存在当前 Chrome 配置的 IndexedDB。协议、主机和端口决定网站来源，因此 `localhost` 与 `127.0.0.1`、不同端口不共享记录。页面刷新或浏览器重启可恢复记录，但前端网页仍需要本地前端服务提供；浏览已保存结果不需要上游引擎或 AI 可用。

只有事务成功后才显示“已保存到本地”。写入失败仍保留内存中的结果，显示“结果尚未保存”和“重试保存”；浏览位置保存失败也会提示并可重试。未成功保存的内存结果会随页面关闭丢失。不持久化进行中状态，不在重新打开时恢复付费请求，不清理旧记录腾空间。

删除按钮需要确认，在同一事务内删除棋谱及关联分析。该棋谱有请求进行时禁用删除。没有自动备份、跨设备同步或多标签页冲突合并。

## 页面分析配置

首页展开“项目分析配置”，或点击页面顶部设置图标。棋谱页点击相同设置图标，可配置 AI 完整接口 URL、API 密钥、最大 token 数、KataGo 程序和权重绝对路径、每手搜索次数、候选点数量（1～3），以及整盘自动分析的停止手数（默认 20）。在棋谱页点击“自动分析整盘”，从第 1 手分析至指定手数（包含该手，且不超过棋谱总手数）。每手完成引擎分析、AI 解释及本地保存后才进入下一手；失败即停。点击“停止”会在当前手完成后停止，刷新页面不会自动恢复。重新启动会重新分析该范围，主要变化保留引擎返回的完整内容。

AI URL 继续使用现有 DeepSeek 协议与后端配置模型。密钥留空保留现有值。配置存于 `backend/settings.json`，文件权限 600，已加入 Git 忽略。保存失败不替换当前运行配置；进行中的分析不允许修改配置。旧的已保存结果保持原样，重新分析时采用新参数。

KataGo 程序与权重同时留空时继续连接原有本机 HTTP 服务；同时填写时，后端按指定路径启动 analysis 子进程，使用项目内固定的 BLACK 视角配置。保存配置不启动引擎或请求 AI。引擎分析仍有 120 秒超时，AI 解释仍有 60 秒超时。
