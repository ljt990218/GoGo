## SGF 允许字段与规则映射

来源：[SGF FF4](https://www.red-bean.com/sgf/properties.html)、[Go properties](https://www.red-bean.com/sgf/go.html)，以及用户的 test.sgf（RU[chinese]、CA[utf8]）。

| 含义 | SGF 字段 | 处理 |
| --- | --- | --- |
| 尺寸 | SZ | 必须明确为 9 / 13 / 19 |
| 编码 | CA | UTF-8 / utf8（忽略大小写）；缺失仍严格按 UTF-8 解码 |
| 游戏类型 / 格式 | GM / FF | GM 仅 1；FF 仅 1～4，缺失按 SGF 默认 |
| 规则 | RU | 去除首尾空白、转小写后 chinese → chinese、japanese → japanese；其他值需用户确认 |
| 贴目 | KM | -50～50，0.5 倍数；缺失需用户确认，非法值拒绝 |
| 初始摆子 | AB / AW / AE | 仅根节点；支持压缩点列表；重叠和无气局面拒绝 |
| 让子数 | HA | 0 或 >=2 的整数；>=2 时要求实际 AB 数量一致，不自动猜摆子 |
| 行棋方 | PL | 根节点 B / W；缺失时 HA>=2 为白，否则黑 |
| 着手 | B / W | 主线，交替；空值或 tt 为停一手（本项目尺寸均<=19） |
| 强制非法落子 | KO | 明确拒绝 |

中途 AB/AW/AE/PL/SZ/RU/KM/HA/GM/FF/CA 拒绝。C、N、LB、LGQ 等注释与标记不参与规则、分析或 AI 输入，不将棋谱自带候选点误作 KataGo 结果。其余不改变局面的未知扩展保留原文，不解释。

本 MVP 的中国规则明确对应 KataGo `chinese`：简单劫、禁止自杀、数子、让子补偿由引擎处理；日本规则对应 `japanese`：简单劫、禁止自杀、数目。不是 `chinese-ogs` / `chinese-kgs`，不擅自扩展映射。完整历史传给引擎，未实现终局裁判。

## 分析交互补充（2026-10-29）

依据最新需求：棋盘候选标记保留 A/B/C，依次展示字母、blackWinRate 胜率和当前行棋方视角的目差。棋盘胜率使用 blackWinRate，toPlay 为 black 时显示 blackWinRate × 100%，为 white 时显示 (1 − blackWinRate) × 100%，保留一位小数；目差仅使用 blackScoreLead（上游 moveInfos[].scoreLead），toPlay 为 black 时原样展示，为 white 时取反，保留一位小数和“目”单位，不显示正数加号。示例：白方行棋，黑方领先 -1.7 / -0.2 / 0.3 目，棋盘对应显示 1.7 / 0.2 / -0.3 目。展示转换不修改存储及 AI 输入中的原始黑方数值。侧栏表格仍明确标注黑方胜率、黑方领先。

scoreStdev 仅在侧栏胜率下显示 σ。根据上述 KataGo 1.17.0 官方文档，它是最终目数的预测标准差，受 MCTS 影响可能偏高，不是胜率置信区间，也不是目差。新分析必须读取 moveInfos[].scoreStdev。内部 Candidate 的 scoreStdev 为非负有限 number；现存已保存记录没有该字段，允许缺失或 null，显示“标准差未提供”，不推算、不补零，重新分析可获取。

自然语言中的有效 GTP 坐标按当前棋盘尺寸识别并高亮；悬停或聚焦可定位。主要变化仅使用 principalVariation，首手立即显示，随后每隔 250ms 推进一步；停一手计入步数和行棋方轮换，提子按现有规则库处理。预览不写入棋谱或存储，离开、失焦、切换局面和分析更新时清除。

## 页面设置契约（2026-10-29）

依据本次用户需求，首页与棋谱页共享项目级配置。只使用以下内部字段，无别名或兼容回退：

| 含义 | 内部字段 | 对应行为 |
| --- | --- | --- |
| AI 完整接口 URL | aiUrl | 替换原 settings.ai_url，保持现有 DeepSeek 请求协议 |
| API 密钥 | apiKey | 仅保存请求传入，空字符串保留当前密钥；读取只返回 apiKeyConfigured |
| 最大 token 数 | maxTokens | 对应现有 max_tokens，正整数 |
| KataGo 程序路径 | katagoPath | 与权重同时填写时使用本地 analysis 命令；两项留空使用原 HTTP 服务 |
| KataGo 权重路径 | katagoModelPath | 对应已有桥接程序的 -model 参数 |
| 每步分析深度 | visits | 对应已定义 maxVisits，正整数 |
| 分析选点数量 | candidateCount | 按现有 order 取前 1～3 个，保持 A/B/C 约定 |

POST /api/settings/read 返回上述非密钥字段及 apiKeyConfigured。POST /api/settings/save 接收上述配置及 apiKey，保存到后端本机 settings.json（权限 600），不存入浏览器。修改只影响后续请求，正在处理局面时拒绝修改。自定义程序沿用已查阅桥接程序的 analysis / -config / -model 命令格式及 BLACK 配置。

用户确认停止步数指整盘自动逐手分析到指定手数。内部配置字段 stopMove 为正整数，默认 20；替换此前未确认的 variationSteps，不保留该字段或别名。自动分析从第 1 手至 min(stopMove, 棋谱总手数)，含结束手数，每手完成引擎分析、AI 解释和本地保存后才进入下一手；失败或保存失败即停止。用户点击停止后完成当前手，不发起下一手。主要变化 pv 保持完整。任务只由显式点击启动，刷新不自动恢复。

## 棋盘候选视觉补充（2026-10-29）

棋盘候选胜率及目差统一为当前行棋方视角。例如白方行棋时，黑方胜率 26.0% 对应白方胜率 74.0%。黑方行棋使用黑色候选背景，白方行棋使用白色候选背景；A/B/C 背景不透明度分别为 100% / 75% / 50%，描边同步淡化，文字保持不透明。候选顺序始终采用引擎 order，不按显示后的胜率重新排序。侧栏表格仍按明确标注的黑方视角展示。
