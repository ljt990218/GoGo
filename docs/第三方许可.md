## 棋谱库使用范围

Sabaki SGF 支持游戏树、分支、转义文本和属性列表；应用在其解析前补充严格结构检查，防止容错解析静默接受损坏文件。只浏览第一条主线，不解析注释中的业务含义。

GoBoard 负责棋块、气与提子；应用显式检查占用、自杀及相邻两局面重复。停一手推进自己的历史，不依赖库的 pass 劫状态。浏览采用每 32 手保存一个内存棋盘检查点，避免为所有节点保留完整棋盘。

sgfmill 的 Board 不保存历史，且允许自行提子；后端显式检查自杀和简单劫，保留完整初始信息与前 N 手着手。前后端均采用 KataGo `chinese` / `japanese` 对应的简单劫范围，不实现终局裁判。

KataGo 程序与权重为用户本机已有资源，本仓库不分发或下载它们。DeepSeek 使用官方 HTTP API，不引入多服务商 SDK。
