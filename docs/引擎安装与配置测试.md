# 引擎安装与配置测试

## 使用方式

在首页或复盘设置中选择轻量、均衡、高阶模型，点击“下载安装”，完成后点击“保存并测试”。无需 Homebrew、编译程序或手填路径。

| 电脑 | 固定下载来源 | 实际系统要求 / 后端 |
| --- | --- | --- |
| Apple 芯片 Mac | KaTrain v1.20.0 arm64 DMG 中的 KataGo 1.18.1 | macOS 26.0+ / Metal |
| Intel Mac | KaTrain v1.20.0 x86_64 DMG 中的 KataGo 1.18.1 | macOS 15.0+ / OpenCL |
| Windows x64 | KataGo v1.18.1 eigen-windows-x64 ZIP | 通用 CPU 版本，不使用 AVX2 专用包 |

上述 Mac 最低版本来自实际发布文件及动态库的 LC_BUILD_VERSION，不能用上游泛指的最低系统要求替代。系统版本不足且没有现有兼容引擎时，页面会说明原因。需要支持更旧的系统时，必须先核实另一个明确的兼容发布物，不猜测或自动切换版本。

Mac 下载完整 KaTrain 发布包，将 KaTrain.app 及依赖复制到 GoGo 管理目录，保留代码签名和相对路径，只执行其中 KataGo，不启动 KaTrain，不装到“应用程序”目录。复制后进行签名校验，挂载使用只读模式，结束时卸载临时磁盘映像。不修改签名或移除隔离属性。

安装目标是本机后端所在电脑。下载文件与解包结果保存在被 Git 忽略的 backend/.gogo/，两个配置路径仍保存在 backend/settings.json。公共下载沿用环境或系统支持的代理设置，不携带 AI 密钥；AI 客户端不改变。下载必须通过固定大小和 SHA-256 校验，失败保留旧配置。

## 模型与现有文件复用

默认轻量版。轻量模型较旧，较大模型不保证适合所有电脑，可在测试失败或较慢时显式切换轻量。

- 轻量：kata1-b10c128-s108710656-d44395882.txt.gz
- 均衡：kata1-b18c384nbt-s9996604416-d4316597426.bin.gz
- 高阶：kata1-b28c512nbt-s13255194368-d5935380940.bin.gz

保持官方压缩格式，直接交给 KataGo 使用，不将 txt 伪装成 bin。每次只下载所选模型，其他档位不会自动下载。

现有引擎检测顺序为保存的程序路径、PATH 中的 katago、Mac 对应 Homebrew 的 bin/katago（Apple 芯片 /opt/homebrew，Intel /usr/local）。只检查文件和执行权限，浏览设置不启动引擎。发现已有引擎后复用其后端，不猜测版本。后来安装了引擎可点击“重新检测引擎”。手动路径位于“高级设置”，两项留空仍使用原本的本机 HTTP 服务。

已有同名模型只检查保存的模型路径和对应 Homebrew 的 share/katago 目录，大小及 SHA-256 与官方一致才可复制复用。受管缓存同样完整校验；中断文件重新下载，不自动继续已中断任务。

## 下载与测试行为

安装过程中显示当前文件的真实进度，未知总量不显示百分比。后台任务与浏览器页面分离，刷新或重开设置可继续查看进度；后端重启后需手动重试，已完成的有效文件可复用。安装、配置保存、分析和测试共用互斥锁。

安装完成仅更新两个引擎字段，不覆盖表单内尚未保存的 AI 设置。保存配置只保存，不调用引擎或 AI；保存并测试先保存当前表单，再在内置 19 路局面进行 32 次搜索，成功后真实调用一次 AI 解释，分别展示结果与耗时。测试不写入棋谱或分析历史，不修改实际复盘的搜索次数。

引擎失败时 AI 显示未执行；缺少密钥、鉴权失败、限流、超时给出明确说明。AI 失败不影响已通过的引擎。快速测试通过不保证较高搜索预算的性能；不会自动重试 AI，避免重复用量。

## 发布信息维护

来源：[KaTrain v1.20.0](https://github.com/sanderland/katrain/releases/tag/v1.20.0)、该版本的构建工作流和 PyInstaller spec、实际 DMG 包结构与 Mach-O 最低系统版本；[KataGo v1.18.1](https://github.com/lightvector/KataGo/releases/tag/v1.18.1)；[官方模型列表](https://katagotraining.org/networks/)。

真实地址、大小、摘要、安装格式、应用包名、最低系统版本和包内入口固定登记于 backend/engine-downloads.json。模型元数据只使用官方训练 API 的 name、model_file、model_file_bytes、model_file_sha256；GitHub 发布文件只使用已核实的 name、browser_download_url、size、digest。不接受浏览器指定 URL、存储目录或命令。

用户无需制作发布包。维护者更换版本时，可用 scripts/register-engine-download.py 从完整发布文件登记大小和 SHA-256；引擎需提供真实发布 URL，文件后缀必须与清单格式一致。该工具不构建、不下载、不上传或运行引擎。更改清单后重新加载后端。
